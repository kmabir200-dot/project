# Project

A Node.js web app built with **TypeScript** and **Next.js** (App Router).

## Tech stack

- Node.js
- TypeScript
- Next.js
- npm

## Status

The repo currently has a Node.js `package.json`. Next.js and TypeScript are not scaffolded yet.

## Setup

```bash
npm install
```

## Scripts

Once Next.js is added, use:

```bash
npm run dev      # local development
npm run build    # production build
npm run start    # run the production build
```
